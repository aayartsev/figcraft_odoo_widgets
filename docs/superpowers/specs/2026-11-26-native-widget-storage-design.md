# Хранилище виджетов: нативный JSON FigCraft + каталог

**Дата:** 2026-11-26  
**Целевая версия Odoo:** 20 Community  
**Статус:** к реализации

Заменяет гибридный формат из [2026-11-26-odoo-widget-format-design.md](2026-11-26-odoo-widget-format-design.md).

## Зачем

Каждый виджет Odoo — файл макета, который FigCraft открывает из коробки. Метаданные для сборки сложных экранов лежат отдельно в каталоге. В репозитории и пайплайне — только текстовые JSON, без бинарных `.figcraft`.

## Хранилище макета

Путь: `widgets/<category>/<snake_class>.json`.

Содержимое — нативный документ FigCraft (тот же JSON, что `document.json` внутри `.figcraft`: `format`, `version`, `name`, `pages`, `nodes`, …).

- Имя файла = `class` в snake_case (`DateTimeField` → `date_time_field.json`).
- Корень виджета на первой странице — слой с именем = `class`.
- Точки вставки детей — фреймы с именем `slot:<имя>`.
- FigCraft: File → Open / MCP `open_file` на этот путь.

## Обёртка (каталог)

Файл [`catalog.json`](../../../catalog.json), `schemaVersion: 2`.

На корне каталога: `odooVersion` (например `"20"`).

В каждой записи виджета:

| поле | смысл |
|------|--------|
| `class` | класс виджета (PascalCase) |
| `category` | категория (как раньше: shell, fields, …) |
| `path` | путь к JSON макета |
| `description` | коротко по-русски |
| `size` | `{ width, height }` — для проверки и будущей сборки |
| `slots` | список `{ name, accepts }` |
| `variants` | минимум `["default"]` |
| `tags` | опционально |

Внутри файла макета этих полей нет. Версию Odoo в файле виджета не дублируем. Словари `slotAnchors` не используем: якорь = фрейм `slot:<имя>`.

### Правило размера

Видимый размер — ширина и высота корня макета в JSON. Поле `size` в каталоге должно совпадать с ними; иначе проверка каталога — ошибка.

## Только текст

Виджеты, каталог, демо и любой будущий выход сборщика сложных макетов — текстовый JSON. Бинарные `.figcraft` / zip не храним и не выдаём как результат пайплайна.

## Утилита `figcraft_build`

В целевом состоянии: команда `validate` — пути, нативный документ, имя файла, слоты, правило `size`.

Временная миграция гибрид → нативный JSON: Document в памяти → `to_json` на диск (без zip). После миграции всего каталога гибридный DSL удаляется.

## Категории

Категории: shell, navbar_widgets, menu, views, fields, discussion, custom.  
Папка `widgets/custom_views/` объединена с `widgets/views/` (2026-11-27).
