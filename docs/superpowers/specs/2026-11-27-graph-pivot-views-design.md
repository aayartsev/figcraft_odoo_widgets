# Доводка GraphView и PivotView

**Дата:** 2026-11-27  
**Целевая версия Odoo:** 20 Community  
**Статус:** согласовано, к плану реализации  
**Файлы:** `widgets/views/graph_view.json`, `widgets/views/pivot_view.json`

## Зачем

Сейчас график и сводная таблица — тонкие заглушки (столбцы без осей; одна строка pivot). Нужны узнаваемые представления Odoo для демо и сборки экранов: панель мер, область данных, слот под верхнюю панель действия (`ControlPanel`).

## Подход

Допиливаем существующие JSON в FigCraft (не пересборка с нуля и не встраивание копии ControlPanel). При схлопывании auto-layout в `(0,0)` — absolute на проблемных уровнях, по правилу визуальной доводки.

## Общая раскладка (оба вида)

| Элемент | Решение |
|---------|---------|
| Ширина корня | **1366** (как List / Hierarchy) |
| Высота | под содержимое, ориентир **560–640** |
| Слот | `slot:control_panel` (~46px), в каталоге `accepts: ["ControlPanel"]` |
| Фон области вида | `#F8F9FA` |
| Демо-данные | Sales-подобные (месяцы, этапы, суммы), без живой БД |
| Иконки | `vector`, не текстовые глифы |

## GraphView

Корень первой страницы — `GraphView` = **столбчатый** вид.

Под слотом CP:

1. **Панель мер/режима** (~40px): Measure (например Untaxed Amount), Group By (например Salesperson), переключатель типов bar / line / pie (активный: фон `#E7E3F2`, штрих `#71639E`; остальные обводка `#DEE2E6`, иконка `#6C757D`). Допустимы приглушённые Order / Stacked.
2. **Область графика:** оси X/Y с подписями, сетка `#DEE2E6`, столбцы `#71639E`, легенда при необходимости.

Соседние кадры (не подменяют корень):

| Кадр | Содержимое |
|------|------------|
| `variant:line` | та же оболочка; линия + точки вместо столбцов |
| `variant:pie` | круговая + легенда справа (сегменты в оттенках бренда / нейтралях) |

Каталог: `slots` с `control_panel`; `variants`: `bar`, `line`, `pie` (корень = bar); обновить `size` и `description`.

## PivotView

Корень `PivotView` — **заполненная** сводная.

Под слотом CP:

1. **Панель мер** (~40px): Measures (Count / Untaxed Amount и т.п.); справа по желанию вторичные иконки (Insert in spreadsheet / Download) без перегруза.
2. **Таблица:** угол (метка группировки строк) · колонки-этапы · строки с шевроном-`vector` · числовые ячейки · Total по строке/столбцу (фон `#F8F9FA`, чуть жирнее).
3. В default уже видно **1–2 уровня** группировки (частично раскрыто); отдельный `variant:expanded` не делаем.

Соседний кадр:

| Кадр | Содержимое |
|------|------------|
| `variant:no_data` | слот CP + панель мер; в центре текст вроде «No data to display», без таблицы |

Каталог: `slots` с `control_panel`; `variants`: `default`, `no_data`; обновить `size` и `description`.

## Документация и проверка

- Обновить `description` / `size` / `slots` / `variants` в `catalog.json`.
- Отметить оба виджета в `dist/widget_qa_checklist.md` после визуальной проверки.
- При необходимости одна строка в README / спеке формата — только если меняется смысл категории (сейчас не требуется).
- `validate` каталога; `screenshot` корня и variants с явным `document`; после `save_file` — pretty text JSON, `"name"` = класс виджета.
